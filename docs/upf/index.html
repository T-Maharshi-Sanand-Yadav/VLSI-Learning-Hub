A power domain is a logical power-intent grouping; different voltage rails do not automatically require separate power domains.

UPF commands (Tcl)

# Create power domains for A and B
create_power_domain PD_A -elements {A}
create_power_domain PD_B -elements {B}

# Create and connect supply ports/nets
create_supply_port VDD1
create_supply_port VDD2
create_supply_port VSS
create_supply_net VDD1
create_supply_net VDD2
create_supply_net VSS
connect_supply_net VDD1 -ports VDD1
connect_supply_net VDD2 -ports VDD2
connect_supply_net VSS  -ports VSS

# Assign primary supplies to each domain
set_domain_supply_net PD_A -primary_power_net VDD1 \
    -primary_ground_net VSS
set_domain_supply_net PD_B -primary_power_net VDD2 \
    -primary_ground_net VSS

A low-to-high crossing translates a 1.0 V signal to a level suitable for the 2.0 V receiving domain.

UPF commands (Tcl)

# Insert level shifters for PD_A → PD_B
set_level_shifter LS_A_TO_B \
    -domain PD_A \
    -elements {A/*} \
    -applies_to outputs \
    -location self \
    -rule low_to_high

# Insert isolation on outputs of PD_A
set_isolation ISO_A \
    -domain PD_A \
    -applies_to outputs \
    -clamp_value 0 \
    -isolation_signal iso_en \
    -isolation_sense high \
    -location parent \
    -elements {A/*}

What each low-power cell does

Level shifter

Voltage translation

Used when a signal crosses between voltage domains that are not directly compatible. Direction and voltage range must match the library cell and tool rule.

Isolation cell

Safe output while a domain is off

Clamps signals to a defined value when the source domain is powered down, preventing unknown or invalid values from propagating.

Implementation checklist

1. Confirm the UPF version

Choose the IEEE 1801 revision supported by your synthesis and implementation tools.

2. Check library support

Verify available level shifters, isolation cells, legal voltage ranges, and cell mapping rules.

3. Validate the intent

Run the tool's UPF consistency checks and review generated reports before synthesis or place-and-route.

Design reminder: If A and B can be powered down independently, separate power domains are usually the more useful model. If they share one power switch but operate at different voltages, model the voltage areas and supply connectivity according to the implementation methodology and tool support.
