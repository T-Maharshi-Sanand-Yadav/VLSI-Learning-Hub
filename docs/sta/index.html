Static Timing Analysis (STA)

Learn setup and hold timing, slack calculations, SDC constraints, timing paths, clock uncertainty and report interpretation through practical examples.

1. STA fundamentals

Understand launch and capture clocks, data arrival time, required time, setup checks and hold checks. Start with a single register-to-register path and draw the timing diagram before calculating slack.

2. Setup and hold slack

Practice the difference between maximum-delay setup analysis and minimum-delay hold analysis. Include clock latency, skew, uncertainty and library setup/hold constraints in worked examples.

3. SDC constraints

Study create_clock, set_input_delay, set_output_delay, set_clock_uncertainty, set_input_transition and set_load. Explain the intent and units for each constraint.

4. Read timing reports

Identify startpoint, endpoint, path group, clock path, cell delay, net delay, arrival time, required time and slack. Use anonymized or self-generated examples and explain each line.

5. Synthesis vs. routed timing

Compare estimated interconnect before place-and-route with extracted or estimated parasitics after implementation. Explain why net delay and timing can change between stages.

6. Practice quiz

Create original questions with worked answers. For each answer, explain the calculation and why the distractor options are incorrect.

Suggested learning order: timing basics → setup/hold calculations → SDC → report analysis → synthesis and implementation differences. Add your own diagrams and worked calculations before publishing each lesson.
